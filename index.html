ARC COMMAND V0.01 beta

⚡ Vendor console

Arc Command builds and edits client profiles for Arc Adapt and EverDue. A profile is a single file that carries the client's company name, users & roles, granted features, equipment field libraries and test checklists.

Protected by a passphrase you set on first use — stored on this device only. Nothing secret is in this page.

How a client gets onboarded

  • Build the profile here (grants = what they're issued; defaults = what starts on).
  • Export — you get an arc-profile-<client>.json file.
  • The client loads it in Arc Adapt or EverDue (Dashboard → load profile). Their admin can then manage users and toggle features within what you granted.
  • To change an existing client: load their profile file here, edit, re-export.
